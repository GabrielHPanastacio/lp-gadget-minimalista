# ErgoMac - Landing Page 💻

Página minimalista de captura de leads para o lançamento de um suporte premium de alumínio para MacBook. Este projeto foca na construção de uma interface limpa e na introdução da interatividade no lado do cliente.

## 🎯 Objetivo do Projeto

Praticar a manipulação do DOM (Document Object Model) capturando eventos de clique e valores de formulários sem recarregar a página.

## 🛠 Tecnologias e Conceitos Aplicados

- **HTML5:** Estruturação semântica e formulários básicos.
- **CSS3:** Uso de Flexbox para centralização absoluta e transições de estado (`transition: background-color`).
- **JavaScript (ES6):**
  - Seleção de nós com `document.querySelector`.
  - Escuta de eventos com `addEventListener('click', ...)`.
  - Leitura de dados do utilizador com `.value`.
  - Lógica condicional (`if / else`) para validação de campos vazios.
  - Alteração dinâmica de estilos (`.style`) e texto (`.textContent`).
